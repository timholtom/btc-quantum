BTQ Deploys BIP-360 on Bitcoin Quantum Testnet

March 19, 2026 — First working implementation of quantum-resistant P2MR transactions goes live on testnet v0.3.0.

← Back to Timeline

What Happened

BTQ Technologies announced the deployment of Bitcoin Quantum Testnet v0.3.0, featuring the first functional implementation of BIP-360 (Pay-to-Merkle-Root / P2MR). This marks the first time quantum-resistant Bitcoin transactions have been executed on a live test network using the BIP-360 specification that was added to the official BIP repository earlier in 2026.

The testnet allows developers and researchers to create, sign, and broadcast quantum-resistant transactions using the new P2MR output type. It includes end-to-end CLI wallet tooling and full RPC support, making it accessible for technical evaluation. At launch, the testnet had more than 50 miners and had processed over 100,000 quantum-resistant transactions.

The release was covered by Bitcoin Magazine, CoinDesk, Decrypt, Quantum Computing Report, and numerous other outlets — reflecting how central the quantum defense narrative has become in 2026.

Technical Details

Version 0.3.0 introduced several key technical features:

  • SegWit version 2 outputs with bech32m encoding, using the new bc1z address prefix
  • Five Dilithium signature opcodes for quantum-resistant verification (based on NIST's ML-DSA standard)
  • P2MR output type that commits directly to a Merkle root of the script tree, eliminating the internal key requirement that makes Taproot vulnerable
  • Full CLI wallet tooling and RPC support for creating and signing P2MR transactions end-to-end

The P2MR approach specifically addresses the vulnerability introduced by Taproot's key-path spend mechanism. While Taproot enables scripting for the Lightning Network and BitVM, it exposes public keys on-chain, making them susceptible to Shor's algorithm on future quantum hardware. BIP-360 maintains current scripting functionality without exposing public keys to quantum-based attacks.

Why It Matters

This deployment is significant for several reasons:

Proof of concept: BIP-360 is no longer just a draft specification — it's running code. Developers can now test, break, and improve quantum-resistant Bitcoin transactions in a real environment.
Ecosystem signal: Multiple major crypto outlets and the Galaxy Digital quantum report (published the same week) referenced the testnet deployment as evidence that Bitcoin's quantum defense is progressing. This helps counter the narrative that Bitcoin is ignoring the quantum threat.
Long road ahead: A testnet deployment is far from mainnet activation. BIP-360 co-author Ethan Heilman has estimated that upgrading Bitcoin to post-quantum could take approximately 7 years, requiring extensive review, consensus building, and careful deployment. The testnet is step one of many.

Context: Galaxy & Ark Reports

The testnet launch coincided with a wave of institutional analysis. Galaxy Digital published a report concluding the quantum threat is "real but far from existential," while Ark Invest's report (published days earlier) estimated ~35% of BTC supply sits in theoretically vulnerable address types. Both reports cited BIP-360 development as a positive sign that the community is taking action.

The timing suggests a coordinated awareness moment in the Bitcoin-quantum narrative — the industry is simultaneously acknowledging the risk and demonstrating concrete progress toward solutions.
